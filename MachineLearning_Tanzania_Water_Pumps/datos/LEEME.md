# Datos

Los datos de la competición no se incluyen en este repositorio, porque las reglas de DrivenData no permiten redistribuirlos.

1. Regístrate en la competición [Pump it Up: Data Mining the Water Table](https://www.drivendata.org/competitions/7/pump-it-up-data-mining-the-water-table/).
2. Descarga los ficheros de la pestaña **Data**.
3. Guárdalos en esta carpeta con sus nombres originales:
   - `Training Set Values.csv`
   - `Training Set Labels.csv`
   - `Test Set Values.csv`
