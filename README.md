# Data Science Portfolio – Lama Jaber

Projects from my Master's in Data Science, Big Data & Business Analytics (Universidad Complutense de Madrid), with a focus on public health.

| Project | Question | Tools |
| --- | --- | --- |
| [Smoking and lung cancer mortality in Spain](smoking-lung-cancer-spain/) | Is the fall in smoking in Spain showing up in lung cancer mortality? | Python, pandas, matplotlib, interactive HTML dashboard |
| [Child and perinatal mortality in Venezuela](unicef-venezuela-child-mortality/) | How have neonatal, infant and stillbirth rates in Venezuela changed since 2000? | MongoDB (CRUD, aggregation pipelines, window functions), Excel |
| [Predicting broken water pumps in Tanzania](tanzania-water-pumps/) | Which water points are functional, need repair or have stopped working? | Python, scikit-learn (Random Forest, Gradient Boosting, model comparison) |
| [Blood pressure, cholesterol and an antihypertensive drug](blood-pressure-statistics/) | Does the drug lower systolic blood pressure, and how is pressure related to cholesterol? | Excel (descriptive statistics, outliers, linear regression, confidence intervals, hypothesis tests) |
| [Data mining on employee salaries](salary-data-mining/) | What drives salary, and which employee profiles exist? | Python, statsmodels (regression diagnostics, robust errors), scikit-learn, factor analysis, hierarchical clustering |

The analyses and reports are written in Spanish.
